# Writing For Agents

Apply the [shared Ponytail method](../../../skills/shared/PONYTAIL.md) within this workflow's scope.

Use the [ASD-STE100 and project language rules](../../../skills/shared/COMMUNICATION.md) for user-facing text.

Read the [host contract](../COMMON.md), then the
[host-neutral Writing For Agents workflow](../../../skills/writing-for-agents/SKILL.md)
and its pinned reference. Use this host's file tools; no Hermes runtime, Pi extension
or external service is required.

The workflow applies mattpocock's `writing-for-agents` reference, formerly
`writing-great-skills`: sharp pointers, one meaning in one home, positive
instructions, checkable completion criteria, progressive disclosure of reference and
a no-op hunt sentence by sentence. It edits documents only within the accepted scope,
keeps every tested contract, and never rewrites pinned upstream bytes or changes what
a skill is authorized to do.

Report the documents changed, lines before and after, meanings moved or deleted,
pointers added and the tests you ran. Writing advice is not authority: preserve
read-only requests, review gates, task state and delivery limits.
