# Plan With Me

Read the [host contract](../COMMON.md). Ask one useful question at a time, using
native user-input tools or chat. Inspect existing docs/source first so questions
resolve product intent rather than facts already in the repo. Decide routine
engineering details yourself. Honor questions-only/read-only without writing files.

Save explicit answers in existing requirement/spec documents when permitted. At
finish, summarize scope, non-goals, acceptance and open questions. Ask for approval
only if your synthesis adds material unaccepted intent. Reconcile accepted decisions
through [Docs Sync](../docs-sync/SKILL.md): full TODO.md tasks, priorities,
dependencies and checks. Do not start implementation merely because a plan exists.
