# Engineering

Apply the [shared Ponytail method](../../../skills/shared/PONYTAIL.md) within this workflow's scope.

Use the [ASD-STE100 and project language rules](../../../skills/shared/COMMUNICATION.md) for user-facing text.

Read the [host-neutral Engineering protocols for Hermes workflow](../../../skills/engineering/SKILL.md) first.

Read the [host contract](../COMMON.md).

Consult the pinned [engineering protocols](../../../skills/engineering/upstream/skills/)
for the current method gap, or the toolset's
[test-suite optimization protocol](../../../skills/engineering/local/test-suite-optimization/PROTOCOL.md)
for slow, redundant or low-signal tests. It defines minimum sufficient regression
protection, not minimum counts: audit by default, save nothing for read-only, or
apply one bounded verified batch under explicit apply/existing implementation
authority without another ceremony. Preserve retained-risk oracles, named bug
traceability, required gates and unknown evidence.

Load only the relevant PROTOCOL.md and necessary references. Use the
[test budget](../../../skills/shared/ENGINEERING-CYCLE.md#test-budget), including
reviewed extra cases for distinct risks rather than a blanket one-test/config ban.
Translate tool names to native tools; do not import another host workflow. Preserve
repository checks and record material methods used.
