# Grill Me

Read the [host contract](../COMMON.md).

Ask one high-value question at a time, grounded in the current repository and plan. Wait for answers; reuse settled decisions. Stop questioning when asked. Save explicit accepted answers through [Docs Sync](../docs-sync/SKILL.md) when requested; a challenge is not implementation authority.
