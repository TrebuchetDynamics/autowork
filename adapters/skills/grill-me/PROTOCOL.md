# Plan With Me: challenge mode (Grill Me compatibility)

Read the [host contract](../COMMON.md). This is a supporting protocol, not a
separate discoverable workflow. Use [Plan With Me](../plan-with-me/SKILL.md) as the
owning workflow; do not recursively reload it from this reference.

Ask one high-value question at a time, grounded in the current repository and
plan. Wait for answers, reuse settled decisions and stop questioning when asked.
Preserve the user's literal request and all questions-only/read-only/no-write,
no-commit and no-push restrictions. Challenge mode does not authorize implementation.
When writes are permitted, reconcile explicit accepted answers through the owning
planner's Docs Sync handoff; do not invent acceptance or ask again about settled intent.
